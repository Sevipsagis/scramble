# Unofficial YouTube Music bridge; personal distribution; public source

We need Guests to add Tracks into the Host’s live YouTube Music Queue. YouTube Music has no supported third-party Queue API, so we use an unofficial/internal bridge on the Host. Distribution is personal (sideload / closed TestFlight), not App Store; the source may still be public on GitHub. Collaborative playlists and a Host-only request board were rejected because they are not a real Queue or still require Host taps while driving.
